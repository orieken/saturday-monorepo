# Integration Guide: Saturday Core + Heatmap

This guide explains how to integrate the **Saturday Playwright Heatmap** plugin with an existing **Saturday Core** based project.

## Integration Philosophy
`saturday-core` uses a **Site Facade** pattern, while `saturday-playwright-heatmap` works via **Playwright Fixtures**. These two patterns are orthogonal and compose perfectly. 

- **Core** handles Page Objects and Logic.
- **Heatmap** handles Runtime Telemetry and Reporting.

You do not need to modify your Page Objects to support the heatmap.

## Setup Steps

### 1. Install Packages
Ensure both packages are installed:
```bash
pnpm add @orieken/saturday-core @orieken/saturday-playwright-heatmap
```

### 2. Define Your Fixtures
In your test setup (e.g., `tests/fixtures.ts`), compose the fixtures.

```typescript
import { test as base } from '@playwright/test';
import { test as heatmapTest } from '@orieken/saturday-playwright-heatmap';
import { MySite } from '../src/site/my-site'; 

// Define a custom test type that includes both your Site and the Heatmap
type MyFixtures = {
  site: MySite;
  heatmap: void; // The heatmap fixture doesn't return a value, it just runs
};

export const test = base.extend<MyFixtures>({
  // 1. Merge in the Heatmap fixture
  ...heatmapTest,

  // 2. Define your Site fixture
  site: async ({ page }, use) => {
    const site = new MySite(page);
    await use(site);
  },
});
```

### 3. Write Tests
Use the composed `test` fixture. The heatmap will automatically track interactions performed by your `saturday-core` Page Objects.

```typescript
import { test } from './fixtures';

test('magic shop flow', async ({ site, heatmap }) => { 
  // 'heatmap' ensures tracking is active

  // Use Saturday Core Page Objects normally
  await site.homePage.visit();
  await site.homePage.login('wizard', 'secrets'); 
  
  // The interactions inside 'login()' are automatically tracked!
});
```

### 4. Analysis
You can then run the **ML Analyzer** on the data generated by these tests to find cold spots in your Page Objects.

```bash
node node_modules/@orieken/saturday-ml-analyzer/dist/index.js heatmap-data
```

## Integration with Saturday Cucumber

If you are using **Saturday Cucumber**, integration is done via global Hooks.

### 1. Manual Integration
Since Cucumber doesn't support Playwright fixtures directly, we provide helper functions.

In your `features/support/hooks.ts`:

```typescript
import { Before, After } from '@cucumber/cucumber';
// 1. Import helpers
import { injectHeatmap, saveHeatmapData } from '@orieken/saturday-playwright-heatmap';

Before(async function(this: WorldImpl) {
  // Ensure browser is open
  await this.openBrowser();
  
  // 2. Inject the tracker
  if (this.page) {
    await injectHeatmap(this.page);
  }
});

After(async function(this: WorldImpl, scenario) {
  if (this.page) {
    // 3. Save data at the end of the scenario
    await saveHeatmapData(
        this.page, 
        scenario.pickle.name, 
        scenario.result?.status?.toString()
    );
  }
});
```

### 2. Analysis
The generated data in `heatmap-data` is identical to the Playwright fixture output, so you can run the same ML analysis:

```bash
node node_modules/@orieken/saturday-ml-analyzer/dist/index.js heatmap-data
```
